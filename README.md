# Gulbenkian’s Lost Legacy

A location-based augmented reality experience that embeds gameplay into a public park using GPS tracking and image recognition.

---

## Overview

Gulbenkian’s Lost Legacy is an AR experience set within a real park environment, where players explore physical space to uncover a hidden narrative. Instead of interacting primarily through a screen, players move through the park, solve riddles, and engage with real-world landmarks.

The project uses location tracking and image detection to anchor digital content to specific places and objects, turning the environment itself into the interface.

---

## Research Focus

The project investigates how interaction can be distributed across physical space rather than contained within a device.

Key questions include:

- How can public spaces function as interactive systems?
- What happens when navigation replaces interface-based interaction?
- How does reducing screen focus affect engagement and awareness?
- How can digital content be meaningfully tied to real-world context?

---

## Interaction Design

- GPS triggers events based on player location
- Image detection anchors interactions to specific physical objects
- Riddles guide movement and exploration
- Progression depends on spatial awareness and observation

The system encourages players to look outward, using the environment as the primary source of information.

---

## Technical Implementation

- **Engine:** Unity (C#)
- **Tracking:** GPS-based location services
- **Recognition:** Image detection for landmark interaction
- **AR Integration:** Anchoring digital content to real-world elements

---

## Design Approach

The project follows a situated design approach:

- Treat the environment as part of the system
- Minimize reliance on continuous screen interaction
- Use movement and perception as core mechanics
- Design tasks that require engagement with real-world context

---

## Outcome

The project demonstrates that:

- Physical environments can act as meaningful interfaces
- Interaction can be distributed across space rather than centralized
- Location and vision-based systems can support exploratory gameplay

---

## Future Directions

- Multi-user shared experiences in public spaces
- Adaptive content based on player movement patterns
- Integration with audio or haptic feedback
- Applications in education and cultural heritage
